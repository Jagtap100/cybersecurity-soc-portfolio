# 🛡️ SOC Security Project

## Project Overview

This project demonstrates practical cybersecurity and Security
Operations Center (SOC) activities including security monitoring,
log analysis, threat detection and incident investigation.

## Objectives

- Monitor security events
- Analyse security logs
- Detect suspicious activities
- Investigate security alerts
- Document security findings
- Understand the SOC investigation process

## Tools & Technologies

- Splunk
- SIEM
- Windows Event Viewer
- Sysmon
- Linux
- Networking

## Key Activities

### 🔎 Security Monitoring

Monitored security events and reviewed logs to identify
unusual or suspicious activities.

### 📊 Log Analysis

Analysed security and system logs to understand user activity,
authentication events and system behaviour.

### 🚨 Threat Detection

Investigated suspicious events and identified potential
indicators of compromise.

### 🔍 Incident Investigation

Reviewed relevant events, analysed available evidence and
documented investigation findings.

## Investigation Process

1. Collect security events
2. Analyse relevant logs
3. Identify suspicious activity
4. Investigate the event
5. Document findings
6. Recommend appropriate response actions
