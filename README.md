🛡️ Colour Me SOC Security Dashboard

📌 Project Overview

Colour Me SOC Security Dashboard is a professional front-end cybersecurity dashboard designed to demonstrate Security Operations Center (SOC) monitoring concepts.

The dashboard provides a visual representation of security alerts, system status, warnings, security events, and monitoring activities.

This project was developed to demonstrate practical knowledge of SOC operations, security monitoring, threat detection, and cybersecurity concepts.

«Note: This is a front-end portfolio demonstration and does not connect to a real SIEM or production security infrastructure.»

💻 How It Works

The dashboard presents simulated security monitoring information through a web-based interface.

Security events are displayed using different severity levels:

- 🔴 High Severity — Critical security activity
- 🟡 Medium Severity — Suspicious or warning activity
- 🟢 Normal — Systems operating normally

The alert counter is simulated using JavaScript for demonstration purposes.
